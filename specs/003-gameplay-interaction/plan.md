# Implementation Plan: Gameplay Interaction

**Branch**: `003-gameplay-interaction` | **Date**: 2026-06-08 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-gameplay-interaction/spec.md`

## Summary

Adds the full gameplay loop to an in-progress round: freehand canvas drawing (stored server-side, polled by all), guess submission (trimmed, case-insensitive, history shared), and first-correct-guess scoring (100 pts) with automatic round-end navigation. Three new REST endpoints added to the rooms router. `RoomStatus` gains `"round-ended"`. `Room` gains `strokes`, `guesses`, and `scores`. `GamePage` gains live canvas rendering, drawer input handling, guess form wiring, and round-end polling.

## Technical Context

**Language/Version**: TypeScript 5.x — Node/Express backend, React 18 + Vite frontend

**Primary Dependencies**: Express, Zod (backend); React, React Router (frontend); HTML Canvas 2D API (frontend — no library needed)

**Storage**: In-memory `Map<string, Room>` — strokes, guesses, scores all added to the existing `Room` object

**Testing**: Vitest (backend `backend/src/tests/`, frontend `frontend/src/tests/`)

**Target Platform**: Local dev server (Node 18+, Vite)

**Project Type**: Fullstack REST API + React SPA

**Constraints**: No WebSockets (strokes sent on pointer-up, polled every 2 s), no DB, no auth

## Data Flow

### Drawing Flow (Drawer)

```
Drawer presses mouse/touch → captures points in local array
Drawer releases pointer → POST /rooms/:code/strokes { participantId, points }
  Route: validates drawer identity, schema, room "in-progress"
  Service: addStroke(code, points) → room.strokes.push({ points })
  Response: { ok: true }
← All clients poll GET /rooms/:code?participantId=...
  Response includes full strokes array
← Clients re-render canvas from full strokes array on every poll tick
```

### Clear Flow

```
Drawer clicks "Clear" → DELETE /rooms/:code/strokes { participantId }
  Service: clearStrokes(code) → room.strokes = []
  Response: { ok: true }
← Clients poll → strokes: [] → canvas re-renders blank
```

### Guess Flow

```
Guesser types + submits → POST /rooms/:code/guesses { participantId, text }
  Route: trims text, rejects empty, rejects drawer, checks room "in-progress"
  Service: submitGuess(code, participantId, trimmedText)
    → push { participantId, playerName, text } to room.guesses
    → if correct AND status === "in-progress":
        scores[participantId] = 100
        status = "round-ended"
  Response: { correct: true | false }
← All clients poll → guesses + scores updated in snapshot
← If snapshot.status === "round-ended": navigate("/results")
```

## File-Level Changes

### `backend/src/models/game.ts`

- Add `Point`, `Stroke`, `Guess` interfaces
- Expand `RoomStatus` to `"lobby" | "in-progress" | "round-ended"`
- Add `strokes: Stroke[]`, `guesses: Guess[]`, `scores: Record<string, number>` to `Room`
- Add same three fields to `RoomSnapshot`

### `backend/src/api/schemas.ts`

- Add `addStrokeSchema`: `{ participantId: string, points: Array<{x: number, y: number}> min 1 }`
- Add `clearStrokesSchema`: `{ participantId: string }`
- Add `submitGuessSchema`: `{ participantId: string, text: string trim min 1 max 100 }`

### `backend/src/services/roomStore.ts`

- `startRoom()`: add `strokes: []`, `guesses: []`, `scores: Object.fromEntries(participants.map(p => [p.id, 0]))`
- Add `addStroke(code, points)`: appends `{ points }` to `room.strokes`
- Add `clearStrokes(code)`: sets `room.strokes = []`
- Add `submitGuess(code, participantId, text)`: resolves `playerName`, appends guess, on first correct sets score=100 and status="round-ended"
- `toRoomSnapshot()`: include `strokes`, `guesses`, `scores`

### `backend/src/api/rooms.ts`

- Import new schemas and service functions
- Add `POST /:code/strokes` — 403 if not drawer; 409 if not in-progress; call `addStroke()`
- Add `DELETE /:code/strokes` — 403 if not drawer; call `clearStrokes()`
- Add `POST /:code/guesses` — 403 if drawer; 409 if not in-progress; call `submitGuess()`

### `frontend/src/services/api.ts`

- Add `Point`, `Stroke`, `Guess` interfaces
- Add `strokes: Stroke[]`, `guesses: Guess[]`, `scores: Record<string, number>` to `RoomSnapshot`
- Expand `status` type to include `"round-ended"`
- Add `addStroke(code, participantId, points)` → `POST /rooms/:code/strokes`
- Add `clearStrokes(code, participantId)` → `DELETE /rooms/:code/strokes`
- Add `submitGuess(code, participantId, text)` → `POST /rooms/:code/guesses` returning `{ correct: boolean }`

### `frontend/src/pages/GamePage.tsx`

- Replace `.canvas-placeholder` div with `<canvas ref>` element
- Drawer: pointer event handlers (mousedown/move/up + touchstart/move/end) capture points; on release call `api.addStroke()`
- Drawer: "Clear" button calls `api.clearStrokes()`; renders no GuessForm (already gated by `!isDrawer`)
- All players: `useEffect` watching `room.strokes` — re-render full canvas on each update
- Guessers: wire `GuessForm` submit to call `api.submitGuess()`; show inline error on empty input; clear form on submit
- All players: render `room.guesses` as guess history list (name + text)
- All players: render `room.scores` in the existing Scoreboard area
- Polling extension: if `room.status === "round-ended"` → `navigate("/results", { replace: true })`
