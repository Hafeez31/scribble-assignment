# Implementation Plan: Game Start & Drawer Flow

**Branch**: `002-game-drawer-flow` | **Date**: 2026-06-08 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-game-drawer-flow/spec.md`

## Summary

When a game starts the host is auto-assigned as the active drawer and a secret word is randomly selected from `STARTER_WORDS`. The backend personalises the `RoomSnapshot` per-requester: the drawer receives the full `secretWord`; non-drawers receive only `wordLength`. Word secrecy is enforced server-side — the word is never included in responses to non-drawers regardless of how they access the API.

Changes are minimal and brownfield-safe: two nullable fields added to `Room` and `RoomSnapshot`, `toRoomSnapshot()` gains an optional `viewerParticipantId` param, and `GamePage` gains the same polling + drawer-awareness UI already established in `LobbyPage`.

## Data Flow

### Game Start (host perspective)

```
Host clicks "Start Game"
  → POST /rooms/:code/start { participantId: hostId }
      Route: validates host, ≥2 players, word list not empty
      Service: startRoom(code)
        - room.drawerId = room.hostId
        - room.secretWord = random from STARTER_WORDS
        - room.status = "in-progress"
        - returns cloned Room
      Route: toRoomSnapshot(room, hostId)
        - secretWord = room.secretWord   ← included (requester IS drawer)
        - wordLength = null
      Response: { room: { drawerId, secretWord: "rocket", wordLength: null, ... } }
  → Frontend: setRoomSnapshot(room) → navigate("/game")
  → GamePage: shows "You are drawing: rocket"
```

### Game State Poll (non-drawer perspective)

```
Guest polls GET /rooms/:code?participantId=guestId  (every 2000 ms)
  → Route: toRoomSnapshot(room, guestId)
      - secretWord = null              ← withheld (requester is NOT drawer)
      - wordLength = 6                 ← letter count included
  → Response: { room: { drawerId: hostId, secretWord: null, wordLength: 6, ... } }
  → Frontend: status becomes "in-progress" → navigate("/game")
  → GamePage: shows "Alice is drawing — 6 letters"
```

## File-Level Changes

### `backend/src/models/game.ts`

- Add `drawerId: string | null` to `Room` interface
- Add `secretWord: string | null` to `Room` interface
- Add `drawerId: string | null` to `RoomSnapshot` interface
- Add `secretWord: string | null` to `RoomSnapshot` interface
- Add `wordLength: number | null` to `RoomSnapshot` interface

### `backend/src/services/roomStore.ts`

- `createRoom()`: initialise `drawerId: null, secretWord: null` on new `Room`
- `startRoom(code)`:
  - Return type: `Room | null` (was `RoomSnapshot | null`)
  - Add empty-list guard (return null with distinct signal, or handle in route)
  - Assign `room.drawerId = room.hostId`
  - Assign `room.secretWord = STARTER_WORDS[Math.floor(Math.random() * STARTER_WORDS.length)]`
- `toRoomSnapshot(room, viewerParticipantId?: string)`:
  - Add `drawerId: room.drawerId`
  - `isDrawer = viewerParticipantId !== undefined && viewerParticipantId === room.drawerId`
  - `secretWord: isDrawer ? room.secretWord : null`
  - `wordLength: !isDrawer && room.secretWord !== null ? room.secretWord.length : null`

### `backend/src/api/rooms.ts`

- `POST /:code/start`: add empty-word-list guard (`STARTER_WORDS.length === 0` → 409); call `toRoomSnapshot(room, participantId)` instead of using snapshot from `startRoom()`
- `GET /:code`: pass `participantId` from query to `toRoomSnapshot(room, participantId)`
- `POST /` and `POST /:code/join`: optionally pass `result.participantId` to `toRoomSnapshot` (no visible change in lobby state; null fields either way)

### `frontend/src/services/api.ts`

- Add `drawerId: string | null` to `RoomSnapshot`
- Add `secretWord: string | null` to `RoomSnapshot`
- Add `wordLength: number | null` to `RoomSnapshot`

### `frontend/src/pages/GamePage.tsx`

- Add `setInterval(poll, 2000)` + cleanup in `useEffect` (identical pattern to LobbyPage)
- Derive `isDrawer = room.drawerId === participantId`
- Drawer view: show the secret word prominently
- Non-drawer view: show word-length hint and who is drawing
- Show drawer's name to all players
